# SocialCrawl

Unified social media scraper API spanning 50 platforms and ~400 endpoints, with a single JSON response schema across all. Covers social, search/research, e-commerce, and reviews data, with agent-native surfaces including llms.txt, an MCP server, and published agent skills.

## APIs

- **SocialCrawl API** — REST/JSON API providing unified access to 50 social/search/commerce/review platforms via ~400 endpoints, authenticated with an x-api-key header. Includes a public OpenAPI 3.1 contract and agent-native surfaces (llms.txt variants, agents.txt, and published agent skills). (`https://www.socialcrawl.dev/v1`)

> Confirmed public REST API with live OpenAPI 3.1 spec at https://www.socialcrawl.dev/v1/openapi.json (~8.5MB), base URL /v1, auth via x-api-key header. Agent-native via llms.txt (plus llms-full.txt, per-platform llms-<platform>.txt, agents.txt, and llms.json catalog) and a published agent-skills bundle installed via 'npx skills add socialcrawl/skills'. The MCP server is LOCAL/stdio only (installed via 'npx -y socialcrawl-mcp' for Claude Code/Desktop, Cursor, Windsurf) — no hosted/remote MCP HTTP endpoint is published, so it is NOT cataloged as an MCPServer property. No AsyncAPI, GraphQL, or Postman collection advertised. Pay-per-call credit pricing; GET /v1/status is public and free.
